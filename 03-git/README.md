# 03 — Git

Module d'une journée sur le versionnement de code avec **Git** et le travail collaboratif via **GitHub**.

## Compétences
- Faire un mémo Git (status, diff, add, commit, log, push, pull, clone)
- Différencier Git et GitHub, et connaître des alternatives à GitHub
- Créer une nouvelle version de son code (enregistrement dans l'historique)
- Synchroniser son répertoire local avec GitHub
- Résoudre des conflits lors d'un merge

## Contenu

### Itération 1 — Premiers pas avec Git
- Réflexion collective sur les outils de travail collaboratif
- Installation et configuration de Git, création d'un dépôt local
- Versionnement de code : `add`, `commit`, `log`, `diff`, `status`
- Rédaction du mémo des commandes Git

### Itération 2 — GitHub et travail collaboratif
- Création d'un compte GitHub et publication d'un dépôt
- Authentification par **clé SSH** (ED25519)
- Synchronisation local ↔ distant : `clone`, `push`, `pull`
- Travail à plusieurs sur un même dépôt : fork, collaborateurs, commits sur des fichiers différents
- Création volontaire d'un conflit de merge, puis résolution

## Git vs GitHub
- **Git** : outil de versionnement décentralisé, qui fonctionne en local
- **GitHub** : plateforme d'hébergement de dépôts Git (collaboration, partage, portfolio)
- Alternatives à GitHub : GitLab, Bitbucket
